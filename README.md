# security-research

一套面向 **明确授权范围内** 安全研究的技能文档包，入口是 [SKILL.md](SKILL.md)。

覆盖从授权判断到可复核报告的完整链路：资产与接口发现 → 业务建模 → 按企业/用户影响选假设 → 最小验证与恢复 → 报告与定级复核。

## 重要声明（先读，再动手）

1. **本仓库不是授权书。** 它不授予任何目标的测试权限。实际测试必须同时满足资产授权与动作授权，两者分别判断：读取页面、扫描端口、发送短信、修改订单不具有相同权限，自有账号也不自动使测试动作获准。
2. **平台规则条目是使用方整理，不是官方原文。** `policies/` 下各平台条目由公开公告与细则整理而来，可能与官方现行文本存在措辞差异。动手前必须核对官方原文；官方更严时以官方为准。
3. **项目条款优先于通用协议。** 个别平台条款更严时（例如要求只在自己创建的账号之间互测、禁止接触线上用户账号、限定可读取数据组数），以项目条款为准，见 [项目规则库索引](references/policies/index.md)。
4. **经验语料只是线索。** [语料索引](references/research/corpus-index.md) 及其下属语料为他人自述的归档转写，未经复现；只作载荷与思路参考，不构成攻击指引，也不构成可执行建议。
5. **对本仓库的修改不等于对平台规则的修改。** 若你按自己的授权与风险偏好调整了本文档口径，请在提交说明与文档内注明，避免下游误认为平台官方文本已变更。

## 越权（访问控制）的动作口径

读取与写入分开定界：

- **增、删、改**：仅限自己控制的账号和内容，并记录恢复结果。
- **查（读取）**：可以对他人账号进行操作，用于证明跨账号可见性；但只用已知对象标识、只取证明所需的最小对象与字段，不遍历真实用户 ID、不批量导出、不留存也不对外传播他人数据。
- **项目条款更严时以项目条款为准**（见上条第 3 款）。

判定要点：HTTP 200、存在响应、UI 显示成功都不充分；需证明本来无权的身份确实读到了另一账号下的唯一内容，或确实完成了被禁止的变更。详见 [对象、功能与字段级访问控制](references/by-type/idor-access-control.md)。

## 自检与检索

```bash
python3 scripts/check_structure.py      # 校验索引与链接完整性、叶子体积、语料指针位置
python3 scripts/search_research.py -h   # 检索本地语料元数据（不联网、不抓取来源）
```

`scripts/build_research_index.py` 用于为一个固定的本地语料检出重建索引，同样不联网、不执行来源内容。

结构校验通过时应输出「索引完整性检查通过」，退出码为 0。改动文档后建议先跑一次再提交。

## 维护约定

- 本仓库是技能文档的**唯一来源**；部署到客户端技能目录时整体同步，避免本地副本与仓库漂移。
- 平台规则类文件改动时，同步更新该文件内标注的来源与核对日期。
- 类型叶子只做方法论，判例与语料回写到 `research/` 并在叶子开头保留指针，防止经验入口被埋进附录。
